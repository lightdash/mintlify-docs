title: "Attio"
description: "Query Attio companies, people, deals, users and workspaces live from Explore and AI agents"

The Attio [live data source](/integrations/live-data-sources) reads the records of your Attio workspace's standard objects: companies, people, deals, users and workspaces. Lightdash turns each query into an Attio records query and shows the records Attio returns. CRM data stays in Attio. It's a [level 2](/integrations/live-data-sources#integration-levels) integration: its API filters records, without totals.

## Before you start

- **Live data sources enabled** for your organization. See [Live data sources](/integrations/live-data-sources).
- **Developer or Admin role** in the Lightdash project.
- **An access token** with the `record_permission:read` and `object_configuration:read` scopes. Create it in your Attio workspace settings under **Developers**. Add `user_management:read` to see owner names.

One source reads every standard object. Custom objects aren't supported yet.

## Connect Attio

1. On the nav bar, click **Browse** → **Semantic Layer**.
2. In the sidebar, select **Live data sources**, then click **Add**.
3. Select **Attio**.
4. Enter the **Access token**, then click **Test**.
5. Under **Details**, check the **Name** and **Explore prefix**. People see the name in Explore and agents use it to refer to the source. The prefix is filled in from the name and can't be changed later. See [Explore prefix](/integrations/live-data-sources#explore-prefix).
6. Click **Add source**.

Lightdash adds a table to Explore for each object: **Companies**, **People**, **Deals**, **Users** and **Workspaces**.

An object your token can't read, or one your workspace hasn't turned on, keeps only its built-in fields. Querying it shows an error saying what to change.

## Dimensions

| Dimension | Notes |
| --- | --- |
| Record ID, URL | The record's ID and its link in Attio |
| Created | The day the record was created, in UTC |
| One for each attribute of the object | Read from Attio when you add the source, up to 300 per object. Archived attributes and attribute types Lightdash can't read are skipped |
| *Status* entered at | For each status attribute, such as a deal's stage: when the record entered its current status, in UTC |
| *Owner* name | For each actor reference attribute, such as a deal's owner: the workspace member's name. Needs the `user_management:read` scope; empty without it, and for owners that aren't members |

To read the attributes again after you add one in Attio, click **Refresh** next to **Fields** on the source's **Settings** tab. Fields a refresh finds start out of use; turn them on in the source's fields. An attribute's field is named after its slug, so renaming an attribute's title in Attio doesn't change it.

Text, number, rating, date, checkbox, select, status, currency, name, email address and domain attributes can be filtered. Phone numbers, locations, record references, actor references and interactions can be shown but not filtered, as can the entered at and name fields. The tables have no metrics.

## Supported features

| Feature | Available |
| --- | --- |
| Filters on dimensions, with several values each | Yes |
| OR filters and nested filter groups | Yes |
| Filters on metrics | No |
| Table calculations, custom metrics and custom dimensions | No |
| Period-over-period comparisons, pivots and date zoom | No |

## Limits

| Limit | Value |
| --- | --- |
| Most rows per query | 9,999 |
| Timeout | 30 seconds per request |
| Queries at once | 3 per source |
| Calls per minute | 600 per source |
| Calls per hour | 20,000 per source |

When a query matches more than 9,999 records, Lightdash shows an error rather than a partial result. Add a filter.

## Example questions

- *"Companies created in the last 30 days."*
- *"Deals in the Won stage, with their value."*
- *"Open deals by owner, with when they entered their stage."*
- *"People at companies in the United Kingdom."*

## Troubleshooting

**Attio rejected the access token.** Create a new token and update the source.

**The access token can't read this object.** Give it the `record_permission:read` and `object_configuration:read` scopes.

**This Attio table is from before one source read every object.** Sources added when Attio read one object keep their old **Records** table until you refresh them. Click **Refresh** next to **Fields** on the source's **Settings** tab before editing its fields; afterwards use its Companies, People, Deals, Users or Workspaces table. Fields a refresh finds start out of use, so turn on the ones you need.

**This Attio workspace doesn't have this object turned on.** A workspace admin turns it on in Attio's workspace settings under **Objects**.

**Owner names are empty.** Give the token the `user_management:read` scope.

**Attio couldn't run this query.** Check the filter values, or use fewer filters and sorts.
