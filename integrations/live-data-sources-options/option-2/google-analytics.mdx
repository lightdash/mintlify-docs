The Google Analytics 4 [live data source](/integrations/live-data-sources-options/option-2) reads one GA4 property through the Google Analytics Data API. Each query is one report request, and Lightdash shows the results as they come back from Google.

## Before you start

- **Admin role** in the Lightdash project.
- **A Google account that can read the property**, with at least the Viewer role in Google Analytics.

## Connect Google Analytics 4

1. Click **Browse** → **Semantic Layer**, select **Live data sources**, then click **Add**.
2. Select **Google Analytics 4**.
3. Enter a **Name**, such as `Google Analytics`, and click **Continue to Google**.
4. Sign in with your Google account and allow read-only access to Google Analytics.
5. Back in Lightdash, pick the property the source reads.

Lightdash reads the property's key events and custom metrics, and adds a **Report** table to Explore. Queries run with the Google account that signed in. To change it, choose **Sign in again** from the source's menu.

## Fields

| Dimension | Notes |
| --- | --- |
| Date | In the property's time zone |
| Year and month | `YYYYMM`, such as `202610` |
| Country, City | From the user's IP address; rare cities can be grouped into `(other)` |
| Device category, Platform | `desktop`, `mobile`, `tablet`; web, Android or iOS |
| Session source, Session medium, Session campaign, Session default channel group | Where the session came from |
| First user source | Where the user first came from |
| Landing page, Page path | Page path is event-scoped |
| Event name | Such as `page_view`, `purchase` or a custom event |
| New or returning | `new` for a first visit, `returning` otherwise |
| Item name | Item-scoped; only works with item metrics |

| Metric | Notes |
| --- | --- |
| Active users, Total users, New users | Daily values don't add up to a weekly total |
| Sessions, Engaged sessions, Engagement rate, Average session duration (s) | |
| Views, Event count, Key events | Your key events are also added as separate metrics |
| Total revenue, Ecommerce purchases | |
| Item revenue, Items purchased, Items viewed | Item metrics |

Custom metrics defined in the property are added too. Click **Refresh fields** after you add a key event or custom metric in Google Analytics. See [Fields](/integrations/live-data-sources-options/option-2#fields).

## Combination rules

Google Analytics only answers some combinations of fields:

- A query can use at most **9 dimensions** and **10 metrics**.
- **Item name** only works with item metrics: Item revenue, Items purchased and Items viewed.
- **Page path** is event-scoped. Splitting sessions or users by page counts a session once for each page it visited.

Lightdash checks these rules before calling Google and tells you which field to remove.

## Limits

| Limit | Value |
| --- | --- |
| Default date range | Last 28 days, when the query has no filter on Date |
| Most rows per query | 24,999 |
| Timeout | 30 seconds |
| Queries at once | 5 per source |
| Calls per minute | 60 per source |
| Calls per hour | 1,000 per source |

Google Analytics also applies its own quotas per property. The features every live data source refuses, such as table calculations and pivots, are listed in [Limits](/integrations/live-data-sources-options/option-2#limits).

## Example questions

- *"Which channels brought the most sessions in the last 28 days?"*
- *"Weekly active users by device category since the start of the quarter."*
- *"Top landing pages by engaged sessions last month."*
