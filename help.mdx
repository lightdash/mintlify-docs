title: "Help"
description: "How to get support and understand feature stability in Lightdash."
---

If you run into an issue, this is where to find the fastest way to reach the Lightdash team, along with how to capture a HAR file so support can debug browser-side problems with you.

It also covers feature maturity levels, the standardized labels Lightdash uses to signal how stable and widely available a feature is as it develops.
