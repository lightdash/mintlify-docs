User attributes are enforced by the semantic layer, so they apply to every query built from an explore: Explore, charts and dashboards, and AI agents answering in their default (semantic) mode. Anything that runs raw SQL against the warehouse runs outside the semantic layer, and `sql_filter`, `required_attributes` and `any_attributes` do not apply to it:

- The [SQL Runner](/explore/sql-runner)
- [SQL mode](/agents/use-ai-agents#sql-mode) in an AI agent conversation
- The **Run SQL** tool of the [Lightdash MCP server](/agents/lightdash-mcp)
- Custom SQL and subqueries in [table calculations](/explore/table-calculations)

The first three need the `manage:SqlRunner` ability, which Developer and Admin roles hold by default. A user without it cannot run raw SQL from any of those surfaces, whatever an agent's instructions say. If someone needs raw SQL and warehouse-enforced permissions at the same time, require [personal warehouse credentials](/personal-settings/personal-warehouse-connections) on the project so their queries run as their own warehouse user, and put the restrictions in the warehouse.
