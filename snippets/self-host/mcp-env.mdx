| Variable                                    | Description                                                                                                                                 |
| :------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------- |
| `MCP_ENABLED`                                | Enables the Lightdash Model Context Protocol (MCP) server. Requires `LIGHTDASH_LICENSE_KEY`. (default=false)                                   |
| `MCP_RUN_SQL_MAX_LIMIT`                      | Maximum number of rows the MCP `run_sql` tool can return. Does not inherit `AI_COPILOT_MAX_QUERY_LIMIT` (default=5000).                        |
| `AUTH_OAUTH_SERVER_ACCESS_TOKEN_LIFETIME`    | Lifetime in seconds of the access tokens Lightdash's OAuth server issues, including MCP connections (default=3600, 1 hour).                                             |
| `AUTH_OAUTH_SERVER_REFRESH_TOKEN_LIFETIME`   | Lifetime in seconds of the refresh tokens Lightdash's OAuth server issues, including MCP connections; once it expires, the client repeats the browser sign-in flow (default=1209600, 2 weeks). |
