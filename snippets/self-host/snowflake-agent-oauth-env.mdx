| Variable                                    | Description                                                                                                         |
| :------------------------------------------ | :------------------------------------------------------------------------------------------------------------------ |
| `SNOWFLAKE_AI_OAUTH_CLIENT_ID`              | Client ID of the Snowflake agent integration, from the `SYSTEM$SHOW_OAUTH_CLIENT_SECRETS` output.                   |
| `SNOWFLAKE_AI_OAUTH_CLIENT_SECRET`          | Client secret of the Snowflake agent integration, from the same output. Keep it in your deployment secret store.    |
| `SNOWFLAKE_AI_OAUTH_AUTHORIZATION_ENDPOINT` | Snowflake authorization endpoint: `https://<account>.snowflakecomputing.com/oauth/authorize`.                       |
| `SNOWFLAKE_AI_OAUTH_TOKEN_ENDPOINT`         | Snowflake token endpoint: `https://<account>.snowflakecomputing.com/oauth/token-request`.                           |
| `SNOWFLAKE_AI_OAUTH_ACCOUNT`                | Snowflake account identifier. Set it if the token endpoint does not identify the account.                           |
