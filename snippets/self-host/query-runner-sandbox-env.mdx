| Variable | Default | Description |
| :--- | :--- | :--- |
| `E2B_DUCKDB_TEMPLATE_NAME` | `lightdash-duckdb-runner` | E2B template for the DuckDB query runner (`e2b` provider). |
| `E2B_DUCKDB_TEMPLATE_TAG` | Lightdash version | Tag of the DuckDB query runner template to launch. |
| `E2B_PYTHON_TEMPLATE_NAME` | `lightdash-python-runner` | E2B template for the Python query runner (`e2b` provider). |
| `E2B_PYTHON_TEMPLATE_TAG` | Lightdash version | Tag of the Python query runner template to launch. |
| `SANDBOX_DUCKDB_DOCKER_IMAGE` | `lightdash-duckdb-runner:local` | Local image for the DuckDB query runner (`docker` provider). |
| `SANDBOX_PYTHON_DOCKER_IMAGE` | `lightdash-python-runner:local` | Local image for the Python query runner (`docker` provider). |
| `DUCKDB_SANDBOX_MEMORY_LIMIT` | `1GB` | DuckDB memory limit inside the DuckDB query runner sandbox. |
| `DUCKDB_SANDBOX_THREADS` | `2` | DuckDB thread count inside the DuckDB query runner sandbox. |
| `SANDBOX_INPUT_MAX_BYTES` | `67108864` (64 MiB) | Combined size of the query results written into one query runner sandbox. A run whose inputs exceed it fails. |
