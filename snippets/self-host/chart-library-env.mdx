| Variable                                        | Description                                                                                                                                                                                                                                                                                                                                      |
| :---------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LIGHTDASH_CHART_REGISTRY_URL`                  | Base URL of the chart library the instance reads. Unset uses Lightdash's public library at `https://lightdash.github.io/lightdash-library`. Set it to the URL of a [private mirror](/self-host/enterprise-features/chart-library#using-a-private-mirror). An empty value turns the library off and hides the **Chart library** tab.                      |
| `LIGHTDASH_CHART_REGISTRY_CHANNEL`              | Which index the instance reads: `stable` (default) or `next`, which also lists beta chart types.                                                                                                                                                                                                                                                 |
| `LIGHTDASH_CHART_REGISTRY_ALLOW_PRIVATE_HOSTS`  | Set to `true` when the library URL resolves to a private or internal address, such as a mirror inside your network. Lightdash otherwise refuses private addresses. Requests still have to use `https`, redirects are still refused, and the connection stays pinned to the address Lightdash resolved. (default=false)                            |
| `LIGHTDASH_CHART_REGISTRY_AUTHORIZATION_HEADER` | Full `Authorization` header value sent with every library request, for example `Basic <base64>` or `Bearer <token>`. Use it for a mirror that requires authentication. Credentials in the URL (`user:pass@host`) are not supported. Unset sends no credentials.                                                                                   |
| `LIGHTDASH_CHART_REGISTRY_ALLOW_INSECURE`       | Allows a plain `http` library URL and turns off address pinning. For local development fixtures only. Logs a security warning at startup. Do not use it for a mirror; use `LIGHTDASH_CHART_REGISTRY_ALLOW_PRIVATE_HOSTS` instead. (default=false)                                                                                                     |
