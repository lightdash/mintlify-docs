</Info>

[Service accounts](/workspace-admin/service-accounts) are userless, scoped credentials for CLI and API access. They outlive their creator and can be granted org- or project-scoped roles. On self-hosted instances the feature is off by default.

## Prerequisites

- **Enterprise license** — `LIGHTDASH_LICENSE_KEY` must be set on your instance.

## Enable service accounts

Set the following environment variable on your Lightdash deployment:

```bash
SERVICE_ACCOUNT_ENABLED=true
```

Restart the backend. Organization admins can then create service accounts from **Organization settings → Service accounts**. See [service accounts](/workspace-admin/service-accounts) for how to create, scope, and rotate tokens.

## Verifying service accounts

1. Log in as an organization admin.
2. Open **Organization settings**.
3. Confirm the **Service accounts** section appears in the settings menu.

## Troubleshooting

**The Service accounts section is missing from settings.**
Confirm `SERVICE_ACCOUNT_ENABLED=true` and `LIGHTDASH_LICENSE_KEY` are set on every Lightdash container.
