[Embedding](/embed/reference) lets host applications render Lightdash dashboards, charts, [data apps](/self-host/enterprise-features/data-apps), the metrics catalog, and [AI agents](/self-host/enterprise-features/ai-agents) inside their own product, authenticated with a JWT signed by an embed secret. To enable it on a self-hosted instance you set one flag and allow-list the host origins that can iframe Lightdash.

## Prerequisites

- **Enterprise license** — `LIGHTDASH_LICENSE_KEY` must be set on your instance.
- **A host application** — the site or product that will render Lightdash content.
- **[AI agents enabled](/self-host/enterprise-features/ai-agents)** — required only if you want to embed AI agents.
- **[Data apps enabled](/self-host/enterprise-features/data-apps)** — required only if you want to embed data apps.

## Enable embedding

Set the following environment variables on your Lightdash deployment:

| Variable | Example | Purpose |
| --- | --- | --- |
| `EMBEDDING_ENABLED` | `true` | Main switch for embedding. |
| `LIGHTDASH_IFRAME_EMBEDDING_DOMAINS` | `https://app.example.com,https://reports.example.com` | Comma-separated list of origins allowed to iframe Lightdash. Requests from origins not in this list are refused by the browser. |

Restart the backend. Project admins can then generate an embed secret and create embed URLs from **Project settings → Embed configuration**. See [set up embedding](/embed/set-up-embedding) for the in-app steps and [embedding reference](/embed/reference) for JWT structure.

## Optional configuration

| Variable | Default | Purpose |
| --- | --- | --- |
| `EMBED_ALLOW_ALL_DASHBOARDS_BY_DEFAULT` | `false` | When a new embed is created, allow every dashboard by default instead of an empty allow-list. |
| `EMBED_ALLOW_ALL_CHARTS_BY_DEFAULT` | `false` | Same as above, for charts. |
| `EMBED_EVENT_SYSTEM_ENABLED` | `false` | Enables the embed event system so host pages can subscribe to events fired by embedded dashboards. |
| `EMBED_EVENT_SYSTEM_POST_MESSAGE_ENABLED` | `false` | When the event system is enabled, also dispatch events via `window.postMessage` to the parent frame. |
| `EMBED_EVENT_RATE_LIMIT_MAX_EVENTS` | `10` | Maximum number of embed events per rate-limit window. |
| `EMBED_EVENT_RATE_LIMIT_WINDOW_MS` | `1000` | Embed event rate-limit window in milliseconds. |

## Verifying embedding

1. Log in as an admin.
2. Open a project's **Settings → Embed configuration**.
3. Generate an embed secret and create a test URL.
4. Load the URL from an origin listed in `LIGHTDASH_IFRAME_EMBEDDING_DOMAINS`.

If the iframe renders the dashboard, embedding is live.

## Troubleshooting

**The embed URL loads on its own but the iframe is blank.**
The host origin is missing from `LIGHTDASH_IFRAME_EMBEDDING_DOMAINS`. Add it (protocol included, no trailing slash) and restart.

**The embed configuration page in project settings is missing.**
Confirm `EMBEDDING_ENABLED=true` and `LIGHTDASH_LICENSE_KEY` are set on every Lightdash container.

**Embedded pages return a 401 or JWT error.**
Regenerating the embed secret invalidates every URL signed with the old secret. Regenerate all embed URLs after rotating the secret.
