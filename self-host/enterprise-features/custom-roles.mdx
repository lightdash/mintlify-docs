[Custom roles](/workspace-admin/custom-roles) let organization admins define roles with a chosen set of permission scopes, beyond the built-in Admin, Developer, Editor, and Viewer roles. On self-hosted instances the feature is off by default.

## Prerequisites

- **Enterprise license** — `LIGHTDASH_LICENSE_KEY` must be set on your instance.

## Enable custom roles

Set the following environment variable on your Lightdash deployment:

```bash
CUSTOM_ROLES_ENABLED=true
```

Restart the backend. Organization admins can then create and assign custom roles from **Organization settings → Roles**. See [custom roles](/workspace-admin/custom-roles) for how to build and assign them.

## Verifying custom roles

1. Log in as an organization admin.
2. Open **Organization settings → Roles**.
3. Confirm the **Create custom role** action is available.

## Troubleshooting

**The Create custom role button is missing.**
Confirm `CUSTOM_ROLES_ENABLED=true` and `LIGHTDASH_LICENSE_KEY` are set on every Lightdash container, and that you're signed in as an organization admin.
