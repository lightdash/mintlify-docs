[Multi-agent Slack channels](/agents/set-up-agents#slack-channels-single-agent-vs-multi-agent) let a single Slack channel host every AI agent in an organization. Messages posted in the channel are routed to the best-fit agent by the [AI Router](/agents/enable-ai-router). Without this feature, each Slack channel can only be attached to one agent.

## Prerequisites

- **Enterprise license** — `LIGHTDASH_LICENSE_KEY` must be set on your instance.
- **[AI agents enabled](/self-host/enterprise-features/ai-agents)** — `AI_COPILOT_ENABLED=true` with a model provider configured.
- **[Slack integration configured](/self-host/customize-deployment/configure-a-slack-app-for-lightdash)** — the Lightdash Slack app installed on your workspace.

## Enable multi-agent channels

Set the following environment variable on your Lightdash deployment:

```bash
SLACK_MULTI_AGENT_CHANNEL_ENABLED=true
```

Restart the backend. Organization admins can then designate a Slack channel as the multi-agent channel from the **AI Agents** organization settings. See [setting up a multi-agent Slack channel](/agents/set-up-agents#setting-up-a-multi-agent-slack-channel) for the in-app steps.

## Verifying multi-agent channels

1. Log in as an organization admin.
2. Open the **AI Agents** organization settings.
3. Confirm the **Multi-agent channel** selector is present.

## Troubleshooting

**The Multi-agent channel selector is missing.**
Confirm `SLACK_MULTI_AGENT_CHANNEL_ENABLED=true`, `AI_COPILOT_ENABLED=true`, and `LIGHTDASH_LICENSE_KEY` are all set on every Lightdash container.

**Setting a channel fails with "already assigned to another AI agent".**
That channel is currently attached to a single agent via the per-agent Slack integration path. Remove the per-agent attachment first, then set the channel as the multi-agent channel.
