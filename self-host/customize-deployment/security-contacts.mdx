Security contacts are the email addresses Lightdash warns about a critical security advisory before it is published. An organization admin sets them on the **Security** page under **Settings → Organization settings**.

Add up to 10 addresses. Use a group address such as `security@yourcompany.com` rather than one person's inbox, so the warning still arrives when someone is away or has left.

The list belongs to your license, not to one organization. Every organization on the same self-hosted instance sees and edits the same list.

## Requirements

1. **Lightdash v3.420.0 or later.**
2. **An Enterprise license key that validated at boot** — the same [Enterprise license key](/self-host/enterprise-features) your deployment already uses. The page is not shown on Lightdash Cloud.
3. **Your license linked to your company on the Lightdash side** — until it is, the page shows "Security contacts not set up". Contact your Lightdash representative to get this done.
4. **The organization Admin role** — only users who can manage the organization see the page and can change the list.

## Set your security contacts

1. Go to **Settings → Organization settings → Security**.
2. Type an email address and press **Enter**. Repeat for each address.
3. Select **Save**.

To remove an address, select the **×** on it, then **Save**. Saving replaces the whole list, so removing every address and saving clears it.

The same page links to the [published advisories on GitHub](https://github.com/lightdash/lightdash/security/advisories). To be alerted to published advisories automatically, see [When to upgrade](/self-host/upgrading#when-to-upgrade).

## Network egress

If your environment restricts outbound traffic, allow HTTPS (port 443) from your Lightdash backend to:

```text
https://roadmap.lightdash.com
```

This is outbound-only, and it is the same host the [organization roadmap](/self-host/customize-deployment/organization-roadmap) uses. Your backend sends your license key and the list of addresses when an admin opens or saves the page. No organization, user, or usage data is sent, and nothing is stored in your Lightdash database.

If the page says security contacts could not be loaded, check this egress rule first.
